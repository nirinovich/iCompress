# iCompress Domain Model

A lightweight, high-performance lossless data archiver and multi-codec compression suite based on canonical reference algorithms.

## Language

**Archive**:
A self-contained compressed binary container beginning with an `ICMP` header and containing one or more compressed payloads.
_Avoid_: Zip file, bundle, package

**Codec**:
A bidirectional algorithmic implementation comprising an Encoder and a Decoder that guarantees bit-exact roundtrips.
_Avoid_: Compressor, converter, filter

**Payload**:
The compressed byte stream generated by a Codec, stored alongside an uncompressed size and CRC32 verification sum.
_Avoid_: Body, data segment, content

**Sliding Window**:
The dual-buffer structure used by LZ77 consisting of a historical search buffer and a lookahead input buffer.
_Avoid_: Cache, ring buffer

**Inversion Vector**:
The primary index and frequency vector required by the Burrows-Wheeler Transform to reconstruct the original permutation.
_Avoid_: Rotation index, shift key

**Cumulative Range**:
The normalized probability sub-interval $[L_j, R_j] \subset [0, 1)$ narrowed at each symbol step during arithmetic coding.
_Avoid_: Fraction window, frequency span
